# NotesApp

Ez az alkalmazás a "Mobil programozási alapok" egyetemi tantárgy keretében készült házi feladat.

## Funkciók
- Jegyzetek létrehozása, szerkesztése és törlése
- Jegyzetek ellátása címmel, leírással és címkékkel (tags)
- Helyi adatbázis alapú adattárolás

## Technológiai stack
- Nyelv: Kotlin
- Adattárolás: SQLite
